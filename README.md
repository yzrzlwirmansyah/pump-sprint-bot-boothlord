A paper-trading bot for make.fun's Pump.fun Paper Sprint: a fresh-coin sniper that buys very young bonding curves on strong early buy flow and flips them fast on take-profit, stop-loss and trailing-stop exits. 10 SOL of paper money on a 6-hour pump.fun replay.

## Run it

```sh
node main.ts
```
